這一年我在終端機裡試了好幾個 AI agent 工具。它們看起來都是「打一句話，AI 幫你做事」，實際用下來，擅長的事情差很多。

先說結論：**寫程式找 Claude Code 或 OpenCode，要一個每天自動跑、記得你喜好的助理，找 Hermes Agent。**

## Claude Code

Anthropic 自家的命令列 agent。最強的地方是在一個專案裡「把事做完」：讀程式碼、改檔案、跑測試、看錯誤、再改。專案規則寫在 `CLAUDE.md`，它每次開工都會讀。

適合：在現有專案裡加功能、修 bug、重構。

## OpenCode

開源的 CLI agent，可以接不同家的模型。我覺得很實用的有兩個：

- **Plan / Build 兩種模式**：先讓它規劃不准動手，確認方向再切到 Build。
- **`/init` 產生 `AGENTS.md`**：自動幫專案寫一份說明書。

要注意的是網路上很多教學已經過時，登入流程和設定檔格式都改過，照舊文件設定會一直失敗。以官方文件為準。

適合：想自己選模型、想把 agent 放進自動化腳本裡跑的人。

## Hermes Agent

它的定位跟前兩個不同，比較像一個會長期記住你的助理。我選它來做「社群連結整理機器人」的原因是：

- 可以**跨對話記住**我在意什麼主題
- **內建排程**，每天自動跑
- Python 生態，跟我其他工具接得起來

適合：每天定時整理資訊、需要長期記憶的個人助理。

## 怎麼選

| 你想做的事 | 我會用 |
|---|---|
| 在專案裡改程式 | Claude Code |
| 換不同模型、寫自動化腳本 | OpenCode |
| 每天定時跑、記得你的喜好 | Hermes Agent |

工具會一直變，這張表大概半年就要更新一次。但「先想清楚要它做什麼，再挑工具」這件事不會變。
