摳摳 KouKougithub.com/pengwho/koukou

把散在銀行和發票載具裡的摳摳，一筆一筆摳回來。

模擬財政部 App 的協定，把手機條碼的電子發票連品項一起抓回自己電腦上的 SQLite 帳本。登入資料用 AES-256-GCM 包起來、查詢用 HS256 JWT 簽章；被 Cloudflare 擋就換成模仿 Chrome 的 TLS 指紋。下一步是讓 AI 助理阿財幫你分類、用白話查帳，再做成 MCP server 讓 Claude 直接讀帳本。

網頁按鈕 → 逐月同步 → 401 自動重登 → AES 信封＋JWT → 財政部 API → SQLite 帳本 → 本機網頁
  • Python
  • FastAPI
  • SQLite
  • curl_cffi
  • Playwright
  • GitHub Actions
