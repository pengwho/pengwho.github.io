# pengwho.com

彭千湖的作品集兼部落格。一頁手刻 HTML，沒有建置步驟，push 就上線。

## 新增一篇文章

在 `posts/` 資料夾新增一個 `.md` 檔，檔名用英文（例如 `my-new-post.md`），最上面寫好這一段：

```markdown
---
title: 文章標題
date: 2026-10-20
column: 工具人日記
summary: 一句話摘要，會顯示在首頁文章列表。
---

正文從這裡開始，用 Markdown 寫。
```

存檔（commit）之後，首頁的「最新文章」和對應專欄的盒子都會自動出現這篇。

- `column` 要跟首頁盒子上的名字一字不差：工具人日記、AI 試吃室、收納控、房間改造中、客廳劇院、走出台灣、摳摳理財、轉職筆記
- 想先放題目、還沒寫完：加一行 `draft: true`，它會以「草稿｜」出現在專欄盒子裡，但點不開、也不會出現在最新文章。寫完把這行刪掉就發表了
- 文章最上面不用再寫 `# 標題`，網站會用 `title` 自動加上
- 每篇文章都有自己的網址：`https://pengwho.com/#p-檔名`（不含 `.md`）

## 文章清單是怎麼讀的

首頁會向 GitHub 詢問 `posts/` 資料夾裡有哪些 `.md` 檔，所以新增文章不需要改其他檔案。

如果 GitHub 暫時查不到（例如短時間內被訪客刷太多次），會改讀 `posts/index.json`。這份清單偶爾手動補一下就好，不更新也不影響平常運作。

## 改作品、經歷或專欄名稱

這些不常變，直接改 `index.html`：

- 作品卡片：搜尋 `<article class="tool"`
- 部落格專欄盒子：搜尋 `<span class="label">`，盒子名稱改了，文章的 `column` 也要跟著改
- 經歷：搜尋 `<div class="bin">`
